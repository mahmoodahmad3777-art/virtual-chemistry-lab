مختبر الكيمياء الافتراضي الذكي


مشروع تعليمي تفاعلي يهدف إلى تطوير تعلم الكيمياء من خلال التجارب الافتراضية والمحاكاة الرقمية ومساعد الذكاء الاصطناعي.


المميزات




تجارب كيميائية افتراضية تفاعلية.


عرض تخطيطي للجزيئات قبل التفاعل وبعده.


مساعد ذكي للإجابة عن الأسئلة الكيميائية.


سجل للتجارب وتحليل النتائج.


إمكانية تنزيل بيانات التجارب بصيغة CSV.




التقنيات




HTML وCSS وJavaScript


Node.js وExpress


OpenAI API




التشغيل


يتم تشغيل المشروع باستخدام Node.js بعد تثبيت الاعتماديات وإعداد متغيرات البيئة المطلوبة.
